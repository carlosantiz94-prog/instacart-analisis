# Proyecto de Exploración de Datos - Instacart

**Aprendiz:** _Carlos Santis_

## Descripción del Proyecto
Este proyecto contiene el análisis exploratorio de datos (EDA) del conjunto de datos de Instacart utilizando Python y Pandas.

## Estructura del Repositorio
- `data/`: Contiene los archivos de datos CSV (ignorados en Git).
- `notebooks/`: Contiene los cuadernos de Jupyter para las pruebas y el análisis.
  - `00_entorno.ipynb`: Comprobación del entorno de ejecución.
  - `01_exploracion_instacart.ipynb`: Análisis exploratorio de Instacart.
- `requirements.txt`: Dependencias del proyecto.
